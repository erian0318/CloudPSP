# CloudPSP

Играй в игры с ноутбука на PSP через Wi-Fi. Игра запускается на ПК, картинка идёт на PSP потоком JPEG, а кнопки PSP превращаются в виртуальный геймпад Xbox 360.

> ⚠️ Экспериментальный проект. Большая часть кода написана с помощью ИИ и проверена только на одной конфигурации (см. «Проверено»). Задержка заметная, динамичные игры (шутеры, файтинги) играются плохо.

## Как это работает

- **На ПК** (Python): снимает экран или окно игры, уменьшает до 480×272, сжимает в JPEG и отправляет на PSP по TCP (порт 5006). Принимает кнопки по UDP (порт 5005) и эмулирует геймпад через ViGEmBus.
- **На PSP** (C, PSPSDK): подключается к Wi-Fi, принимает кадры, декодирует аппаратным декодером `sceJpeg` и выводит на экран. Параллельно шлёт состояние кнопок и стика.

## Проверено

- PSP-3004 с кастомной прошивкой ARK-4
- Windows 10 22H2
- Wi-Fi: раздача с телефона, 2,4 ГГц, защита WPA2 Personal
- Игра: Half-Life (в оконном режиме)

Другие конфигурации не проверялись.

## Что нужно

- PSP с кастомной прошивкой (запускающей homebrew)
- ПК с Windows 10/11
- Wi-Fi сеть 2,4 ГГц с защитой **WPA2** (PSP не умеет WPA3)
- [Python 3.11–3.12](https://www.python.org/downloads/) (при установке отметь «Add python.exe to PATH»)
- Драйвер [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases) (проект больше не развивается, но работает)
- Docker Desktop нужен только если хочешь собрать программу для PSP сам

## Установка

1. Установи Python и ViGEmBus, перезагрузи ПК.
2. В папке `server` выполни:
   ```
   python -m pip install -r requirements.txt
   ```
3. Скопируй папку `psp-ready/CloudPSP` на карту памяти PSP в `PSP/GAME/`.
4. В этой папке на карте переименуй `config.example.txt` в `config.txt` и впиши:
   - 1-я строка: IP-адрес ПК в сети Wi-Fi
   - 2-я строка: номер профиля Wi-Fi на PSP (по порядку в «Настройки сети → Инфраструктурный режим»)

Важно: у файлов не должно быть скрытого `.txt` в конце имени (включи показ расширений в проводнике).

## Запуск

1. Подключи ПК и PSP к одной Wi-Fi сети.
2. Запусти игру в оконном режиме или «без рамки».
3. Запусти `server/start_cloudpsp.bat`. Откроется одно окно, в нём покажется IP ПК. **Он должен совпадать с первой строкой `config.txt` на PSP.** Раздача с телефона часто выдаёт новый адрес, поэтому сверяй каждый раз.
4. На PSP открой CloudPSP.
5. Остановка: закрой окно или запусти `server/stop_cloudpsp.bat`.

## Настройки

Файл `server/settings.txt`:

| Параметр | Значение |
|---|---|
| `WINDOW_TITLE` | Часть заголовка окна игры. Пусто = снимать весь экран (подходит для любой игры) |
| `MONITOR` | Номер монитора для снимка всего экрана |
| `FPS` | Кадров в секунду. Если тормозит, поставь 10 |
| `QUALITY` | Качество JPEG 20–90 |
| `MAX_FRAME` | Максимальный размер кадра в байтах |
| `KEEP_ASPECT` | 1 = чёрные полосы, 0 = растянуть на весь экран PSP |

Изменения применяются при следующем подключении PSP, перезапускать сервер не нужно.

Виртуальный геймпад создаётся, когда PSP подключилась, и удаляется, когда она отключилась или сервер остановлен.

## Раскладка кнопок

| PSP | Xbox 360 |
|---|---|
| ✕ ○ □ △ | A B X Y |
| L / R | LB / RB |
| Крестовина | D-pad |
| Start / Select | Start / Back |
| Аналоговый стик | Левый стик |

У PSP нет L2/R2, R3 и правого стика, поэтому игры, которым они нужны, управляются неполностью. Игры только для клавиатуры и мыши не поддерживаются.

Для игр из Steam, если геймпад не реагирует, отключи Steam Input в свойствах игры (вкладка «Контроллер»).

## Сборка программы для PSP (необязательно)

Исходники в `psp-source`. С установленным Docker, в этой папке:

```
docker run --rm -v "%cd%":/src -w /src pspdev/pspdev make
```

(в PowerShell вместо `%cd%` используй `${PWD}`). В папке появится `EBOOT.PBP`.

## Частые проблемы

- **PSP не подключается к Wi-Fi.** Выбери WPA2 Personal и 2,4 ГГц. Перезапусти раздачу и перезагрузи PSP. После выхода из программы лучше перезагружать PSP перед новым запуском.
- **«connect error» на PSP.** Проверь, что IP в `config.txt` совпадает с IP в окне сервера, что сервер запущен и что брандмауэр Windows разрешает Python в частных сетях.
- **Геймпад не виден.** Проверь установку ViGEmBus и тестер геймпада (например, hardwaretester.com/gamepad).
- **Чёрный кадр.** Игра в полноэкранном эксклюзивном режиме. Переключи на «в окне» или «без рамки».
- **Размытая картинка.** Экран PSP 480×272, мелкий текст читается плохо.

## Известные ограничения

- Wi-Fi PSP (802.11b) ограничивает скорость, задержка 100–250 мс и выше.
- Нет звука.
- IP ПК вводится вручную через `config.txt`.
- Предупреждение сборки «stubs out of order» безвредно на проверенной конфигурации.

## Законность

Проект не содержит игр и не помогает их обходить. Используй только легально купленные игры.
